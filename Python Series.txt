We use Shallow Copy and Deep Copy to create copies of objects, especially when working with lists, dictionaries, nested lists, or other mutable objects. The main difference is whether the nested objects are shared or copied.
1-Deep Copy- var = "Hello" -> (var_c=var)

*********
1- Key: It returns the keys only. Eg- Name-Puja, City-Jalandhar, Age- 21
So, It will print (Name, City and Age).

2- Values: It returns the values only. Eg- Name-Puja, City-Jalandhar, Age- 21
So, It will print (Puja, Jalandhar, 21).

3- Items: It returns the keys and values as well. Eg- Name-Puja, City-Jalandhar, Age- 21
So, It will print (Name-Puja, City-Jalandhar, Age- 21).
